# Project Assets & References

Place your project-specific styling and brand assets in this folder (or attach them directly in chat during Step 0 Intake):

1. **`text_style_reference.png`** (or `.jpg`): Screenshot or design mockup showing how you want word-by-word captions styled (font, case, stroke, pill background, highlight color, position).
2. **`element_style_reference.png`** (or `.jpg`): Screenshot or reference frame showing how you want animated SVG / motion graphics styled (stroke weight, doodle vs. geometric, corner treatment, palette).
3. **Brand Fonts & Logos:** `.ttf` / `.otf` font files and `.svg` / `.png` logo assets.
4. **Music File (`.mp3` or `.wav`):** If you provide a music file here or in your project folder, the skill follows the golden rule: **it uses ONLY your music file and never mixes in random stock music.**
